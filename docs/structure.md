## Структура репозитория

### 1. Корневая директория
```
image_processing_orange_pi/
│
├── README.md                  # Основная документация: описание проекта, установка, запуск, зависимости
├── LICENSE                     # Лицензия проекта
├── requirements.txt            # Список Python-зависимостей
├── setup.py                    # Файл для установки пакета (если планируется)
└── .gitignore                  # Игнорируемые файлы (например, данные, виртуальное окружение)
```

### 2. Директория с исходным кодом
```
src/
│
├── data/                       # Модули для работы с данными

|   ├──

│   └── pseudo_labeling.py      # Логика генерации псевдоразметки

│   ├── __init__.py
```

## Ключевые моменты

1. **Модульность**: Каждый компонент (данные, модели, обучение) вынесен в отдельный модуль для удобства поддержки.
2. **Конфигурации**: Используйте YAML-файлы для хранения параметров моделей и обучения — это упрощает эксперименты.
3. **Логирование**: Включите логирование для отслеживания процесса обучения и ошибок.
4. **Тестирование**: Добавьте юнит-тесты для критически важных компонентов.
5. **Документация**: Подробно опишите процесс установки, запуска и использования в `README.md`.
